# Weather App 🌦️

A modern real-time weather application built using HTML, CSS, and JavaScript.  
This app fetches live weather data using WeatherAPI and provides city search suggestions.

---

## 🚀 Features

- 🌍 Real-time weather information
- 🔍 Live city search suggestions
- 🌡️ Temperature display
- 💨 Wind speed
- 💧 Humidity details
- 😎 Feels-like temperature
- 🌫️ AQI (Air Quality Index)
- 📱 Responsive UI
- 🎨 Modern glassmorphism design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- WeatherAPI
